# 🧮 Math Quiz Game

A console-based Math Quiz game built with **C++**.  
The game generates random math questions based on the selected difficulty level and operation type, then evaluates the user's answers and displays the final results.

## ✨ Features

- 🔢 Choose the number of questions
- 🎯 Choose the difficulty level:
  - Easy
  - Medium
  - Hard
  - Mix
- ➕ Choose the operation type:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Mix
- 🎲 Randomly generated questions
- ✅ Automatic answer checking
- 📊 Tracks correct and wrong answers
- 🏆 Displays the final quiz result
- 🔄 Option to play again

## 🛠️ Technologies Used

- **C++**
- **Object-oriented programming concepts**
- **Enums**
- **Structs**
- **Functions**
- **Switch statements**
- **Loops**
- **Random number generation**

## 🎮 How to Play

1. Choose the number of questions.
2. Select the difficulty level.
3. Select the type of mathematical operation.
4. Solve each generated question.
5. Enter your answer.
6. Get instant feedback.
7. View your final score and result.
